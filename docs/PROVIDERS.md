# Provider verification ledger

Checked against official documentation on **2026-09-27**. Documentation review is not a live account test. No paid credentials were supplied. Defaults must continue to work without paid keys; the free path is not a guarantee of Tamil quality or arbitrary own-voice synthesis. Recheck this ledger before activating an adapter or changing models.

## Paid upgrade: Anthropic intent

- API: `POST https://api.anthropic.com/v1/messages`, server-side key only. Structured JSON uses `output_config.format = { type: "json_schema", schema }`; encode `c1/c2/c3` as required properties and validate content after parsing. The old `output_format` request field is deprecated. [Structured output docs](https://platform.claude.com/docs/en/build-with-claude/structured-outputs)
- Current configured candidates from the brief remain listed: `claude-haiku-4-5-20251001` for round 1; `claude-sonnet-5` for later rounds. Listed standard prices are US$1/$5 and US$2/$10 per million input/output tokens respectively. Actual total includes caching and current account terms. [Model table](https://platform.claude.com/docs/en/models/overview)
- SDK is optional: direct server `fetch` avoids a client SDK dependency. The TypeScript SDK documented by Anthropic is `@anthropic-ai/sdk`; pin its version if added. No user data belongs in schema descriptions. [Structured output docs](https://platform.claude.com/docs/en/build-with-claude/structured-outputs)
- Limits are account/tier/model dependent, measured in requests and input/output tokens per minute. Respect 429 `retry-after`; a spend-cap failure is not necessarily retryable. Sollu's own limits are separate. [Rate limits](https://platform.claude.com/docs/en/api/rate-limits)
- Standard commercial API inputs/outputs are deleted within 30 days with documented legal, abuse and feature exceptions. Commercial data is not used for training by default; explicit opt-in programmes differ. Do not claim zero retention without the account agreement. [Retention](https://privacy.claude.com/en/articles/7996866-how-long-do-you-store-my-organization-s-data), [training](https://privacy.claude.com/en/articles/7996868-is-my-data-used-for-model-training)

## Paid upgrade: Sarvam speech-to-text

- `POST https://api.sarvam.ai/speech-to-text`, multipart audio and `api-subscription-key`. `saaras:v3` is a documented model; compare `codemix` and `verbatim` on team clips. REST accepts at most 30 seconds. Use native `fetch`/`FormData`; no SDK package is required. [REST reference](https://docs.sarvam.ai/api-reference/speech-to-text/transcribe), [Saaras](https://docs.sarvam.ai/api/getting-started/models/saaras)
- The published model overview lists Indian-language and English support; recognition accuracy for aphasic Tamil is not established by coverage. Accepted codecs depend on endpoint; inspect the reference for the actual MediaRecorder file. [STT guide](https://docs.sarvam.ai/api/api-guides-tutorials/speech-to-text/overview)
- Starter REST STT is documented at 60 requests/minute, with higher-plan limits and separate streaming/batch limits. Pricing is metered and may include promotional account credits; no enduring free quota is assumed. [Rate limits](https://docs.sarvam.ai/api-reference-docs/ratelimits), [pricing](https://docs.sarvam.ai/api/getting-started/pricing)
- Sarvam's general policy says submitted content can be used to improve models unless opted out, despite a confusing “Default Policy: Opt-In” heading. Obtain account-specific confirmation before uploading personal data; do not infer API exclusion or zero retention. The policy has category-specific retention and legal/backup exceptions. [Privacy policy](https://www.sarvam.ai/privacy-policy)
- Selection, CER, latency and retained-audio consent are **pending**. About ten hackathon clips and at least twenty clips per language for full evaluation are required; never commit speakers' audio.

## Paid upgrade: ElevenLabs clone and TTS

- `POST /v1/voices/add` accepts multipart samples for Instant Voice Cloning; `DELETE /v1/voices/{voice_id}` removes a voice. Consent and a device-bound voice grant are required in Sollu. [Create IVC](https://elevenlabs.io/docs/api-reference/voices/ivc/create), [delete voice](https://elevenlabs.io/docs/api-reference/voices/delete)
- `POST /v1/text-to-speech/{voice_id}` accepts text/model and returns audio; the standard example is `mp3_44100_128`. Server uses `xi-api-key`. Validate the signed text, language, expiry and owning device before any provider call. [TTS endpoint](https://elevenlabs.io/docs/api-reference/text-to-speech/convert)
- `eleven_flash_v2_5` and `eleven_multilingual_v2` list Tamil, Hindi and English; `eleven_v3` also lists Telugu. Published request limits are 40,000, 10,000 and 5,000 characters respectively, well above Sollu's 90-character candidate cap. Vendor latency excludes application/network time. [Models](https://elevenlabs.io/docs/overview/models)
- Pricing page lists Free with 10k credits/month and Starter at US$6/month before taxes with 30k credits and Instant Voice Cloning. The free tier is not a free own-voice clone. Credit conversion varies by model/product; inspect the account's current entitlement. [Pricing](https://elevenlabs.io/pricing)
- Published general concurrency limits include Free 2 and Starter 3; Sollu's queue target is 2. Handle 429 without replaying or resurrecting a cancelled request. [429 guide](https://elevenlabs.io/docs/help-center/technical/api-error-code-429)
- TTS `enable_logging=false` is enterprise-only zero-retention mode. Ordinary history cleanup uses `DELETE /v1/history/{history_item_id}`. Identifying each generation and confirming cleanup success are live-integration checks; an unavailable ID or deletion error must never be reported as deleted. History deletion does not establish deletion from all legal/security backups. [TTS retention parameter](https://elevenlabs.io/docs/api-reference/text-to-speech/convert), [history deletion](https://elevenlabs.io/docs/api-reference/history/delete)
- ElevenLabs may use submitted data to improve models outside excluded plans; the account's Data use toggle opts future submissions out. Disable it before personal samples, record the setting and inform the voice owner. Cloning stores a reusable voice; enterprise TTS zero retention does not remove that requirement. [Training controls](https://elevenlabs.io/docs/help-center/legal/is-my-data-used-to-improve-eleven-labs-ai-models), [zero retention](https://elevenlabs.io/docs/eleven-api/resources/zero-retention-mode)

## Deferred alternatives and evidence

Sarvam cloning supports inline reference audio and saved voice IDs; `/voices/clone` examples use multipart `ref_audio`, optional `ref_text`, text and language. Documentation pages disagree on 12 versus 13 languages, so check the specific route before implementation. Sample and output formats, account eligibility, current limits, pricing and deletion semantics remain an integration gate. [Cross-language guide](https://docs.sarvam.ai/api/api-guides-tutorials/voice-cloning/how-to/clone-across-languages), [model overview](https://docs.sarvam.ai/api/getting-started/models)

OpenAI transcription, ElevenLabs Scribe, self-hosted IndicF5, cloud vision and Web Push remain future routes unless separately implemented and verified. No SDK/model installation, paid request, hosting purchase, or provider deletion was performed by this documentation review. Live provider evidence belongs in [../PROGRESS.md](../PROGRESS.md).
